# 路线图

当前版本为 v0.3.2。已实现功能以 [README](../README.md) 和 [更新记录](../CHANGELOG.md) 为准。以下是待评估的开发方向，不代表已实现功能、确定排期或发布承诺。

## 优先方向

| 方向 | 计划范围 |
| --- | --- |
| 网页兼容性 | 补充 ChatGPT 页面结构夹具，改进消息读取、定位和输入适配 |
| 导出完整性 | 更好地保留页面可读取的引用来源、代码信息和公式，明确生成中与未加载内容的范围 |
| 精细导出 | 选中文本、单个代码块和表格 CSV，便于保存局部内容 |
| 收藏整理 | 标签与筛选，改进主动保存材料的本地检索 |
| 上下文复用 | 将用户选中的消息整理为可编辑的续聊材料，展示实际内容与来源 |
| 提问辅助 | 提供补充背景、明确输出要求等可编辑建议，由用户确认后发送 |

## 后续探索

- 图片内嵌、公式渲染、Mermaid 源码和 Canvas 文本的导出支持。
- 打印入口、更多导出格式和自定义文件名或模板。
- 基于已加载页面的多会话导出，提供进度与取消操作。
- 更多浏览器和界面语言适配，以及浏览器商店发布。

每项能力都需先确认站点数据是否可读取、权限是否必要、存储成本和可测试性。批量能力不依赖未公开的 ChatGPT 内部 API；新增联网或模型调用需先定义清晰的数据范围与用户控制方式。

## 持续维护

除功能开发外，会持续关注键盘操作、长对话性能、导出内容清洗、本地存储错误处理和资料格式兼容。提出建议时，请通过仓库 Issues 说明具体场景与期望行为；实施范围以对应讨论和变更为准。
