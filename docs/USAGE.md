# 使用指南

安装步骤和支持范围见 [README](../README.md)。以下操作均针对当前浏览器中的扩展和 ChatGPT 网页。

## 打开助手

在 ChatGPT 页面点击右侧“使用助手”，或点击扩展弹窗中的“打开增强面板”。弹窗也提供模板、搜索和收藏的快捷入口。

助手可以收起，按 `Esc` 也可关闭。切换标签或收起面板会保留当前表单与滚动位置；这些临时表单在刷新页面后清除。可在“设置”中关闭不需要的模块。

“模板与收藏管理”会打开独立资料管理页，无需先打开有消息的对话。

## 目录与搜索

“目录”按照当前已加载的用户提问排列，点击即可定位，也可使用上一问、下一问和回到底部。

“搜索”支持关键词与角色筛选。输入后可使用上一处、下一处逐个定位；`Enter` 立即搜索并向前定位，`Shift + Enter` 反向定位。最多可导航前 1000 处命中，更多命中时请缩小关键词范围。

两项功能都只处理页面已加载内容，不检索账号的全部聊天历史。在助手标签栏可使用方向键、`Home` 和 `End` 切换模块。

## 模板与引用追问

在“模板”中创建或编辑提示词，使用 `{主题}`、`{受众}` 等形式定义变量。选择“使用”后填写变量，也可补充目标、背景、输出格式和限制条件。

预览会随填写内容更新。手动修改预览后，变量变化不会覆盖修改；需要重新生成时点击“更新预览”。检查内容后再插入输入框。重复插入同一份未变化草稿不会再次追加。

在 ChatGPT 回复中选中一段文字，点击“引用追问”，选择解释、举例、翻译、检查依据或自定义动作，也可在“追问”标签中手动输入引用。自定义动作在“设置”中编辑。

所有插入操作都会追加到已有输入，不会自动发送。输入框不可用时，可使用“复制草稿”。若插入后又手动修改输入，扩展可能无法安全撤销，可使用输入框自身的撤销功能。

## 阅读与收藏

“阅读”中可调整正文宽度、字号和行距，开启专注模式。消息和代码块旁的折叠按钮只改变页面显示，搜索与导出仍读取完整的已加载内容。

点击消息旁的“收藏”可保存该条消息的内容快照、来源、时间和备注。在“收藏”中可以搜索、查看、复制、导出 Markdown、定位来源或取消收藏；取消后有撤销入口。

定位来源前需打开对应会话。如果原消息已修改、未加载或无法唯一识别，扩展会提示无法定位，已保存快照仍然可读。

## 资料空间与备份

在“设置”中可以创建资料空间，分别管理模板、收藏、阅读设置和草稿。创建多个空间后，助手顶部显示切换控件。当前空间选择只作用于当前标签页。

资料空间不自动关联 ChatGPT 账号，也不与官方 Project 同步。切换账号或用途时，请手动选择对应空间。

点击“下载当前空间备份”可导出 JSON 文件。备份包含当前空间的模板、收藏正文、备注、来源和设置，不包含文字草稿，也不包含其他空间或导出弹窗选项。

恢复时先选择备份文件并检查预览，再点击“确认替换当前空间”。此操作会替换当前空间的资料、清除该空间草稿，并关闭草稿保存；当前空间名称与其他空间保留。建议恢复前先备份现有资料。

“清除当前空间资料”会清空当前空间的模板、收藏和草稿，并重置设置。它不会清理其他空间、导出弹窗选项或你已下载的文件。

## 草稿恢复

1. 在“设置”中勾选“草稿”（默认关闭），选择 1、7 或 30 天的保留期，默认 7 天。
2. 开启后编辑 ChatGPT 输入框，扩展会保存文字；不保存附件。
3. 刷新后点击助手顶部的“恢复草稿”，预览、编辑或复制内容，再选择“恢复到输入框”。已有输入会保留，恢复不会自动发送。
4. 同一会话的不同标签页独立保存；列表会标注当前或其他标签页。独立资料管理页可查看当前空间所有会话的草稿。

扩展只有在页面出现对应用户消息、其后的助手回复开始出现文字后才清理已发送草稿；无法确认时会保留，可手动删除。后续新草稿不会因上一条消息的发送确认被清除。

“立即清除当前空间草稿”、关闭草稿功能、清理当前空间或恢复备份都会清除当前空间的已存草稿。到期草稿不再可恢复，并在后续访问或页面定期检查时删除。草稿使用约 350 ms 的保存延迟；浏览器崩溃或扩展失效前尚未写入的内容无法保证恢复。

## 导出对话

1. 打开具体对话，等待希望导出的消息加载完毕和回复结束。
2. 点击助手顶部的“导出”或浏览器工具栏的扩展图标。
3. 选择 Markdown 或 HTML，设置起止消息序号和角色筛选。
4. 需要第 1、3、8 条等不连续消息时，点击“在页面逐条选择”，勾选后点击“完成选择”。页面支持全选、反选和清空，按 `Esc` 取消。
5. 根据需要展开“排版与文件名”或“内容预览”，最后选择“导出文件”或“复制”。

完成逐条选择后会尝试自动打开导出弹窗。如果浏览器阻止打开，可点击“继续导出”重试，或直接点击工具栏扩展图标。选择结果仅临时保留，在弹窗关闭、取消或切换会话后清理。

也可在页面右键快速导出 Markdown / HTML，或使用 `Alt + Shift + M` 快速导出 Markdown。

### 格式与分享

Markdown 使用角色标题、可选 YAML 元信息和消息分隔线；可恢复的公式输出为 `$...$` 或 `$$...$$`。不同阅读器的公式支持可能不同。

HTML 是样式内嵌的单一文件，支持浅色、深色、跟随系统和浏览器打印。文本可离线阅读；远程图片仍依赖原 URL。当前 HTML 不内置 KaTeX / MathJax 公式渲染器。

导出默认可能包含会话标题、来源 URL、导出时间和所选消息正文。分享前请检查文件；可关闭“导出信息”以移除元信息与来源，但正文中的链接和敏感信息仍需自行处理。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 安装或更新后页面没有助手 | 在扩展管理页重新加载扩展，再刷新 ChatGPT 页面 |
| 导出缺少消息 | 确认目标消息已在当前页面加载，并检查消息范围、角色筛选和逐条选择 |
| 模板无法插入 | 等待输入框可编辑后重试，或复制草稿手动粘贴 |
| 收藏无法定位 | 打开来源会话并加载对应消息；原消息变化时使用已保存快照 |
| 提示本地存储失败 | 先复制重要内容，重试或备份后清理不需要的资料 |
| 页面按钮无法打开导出弹窗 | 使用浏览器工具栏的扩展图标 |

若问题仍存在，请按 [贡献指南](../CONTRIBUTING.md) 提供浏览器版本和复现步骤，避免公开真实对话或完整备份。
