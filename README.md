# ChatGPT 使用增强助手

一个本地优先、无第三方运行时依赖的 Chrome / Edge Manifest V3 扩展。提供对话目录、关键词搜索、提示词模板、划词追问、阅读设置、消息收藏，以及 Markdown / HTML 导出。当前版本：**v0.3.2**。

## 已实现功能

### 使用增强（P0）

- 页面右侧统一助手面板，可收起、用 Esc 关闭，所有模块支持独立开关
- 按提问生成对话目录，支持上一问、下一问与回到底部
- 搜索当前已加载对话，按角色筛选、关键词高亮、逐个定位；最多导航前 1000 处命中
- 提示词模板的创建、编辑、删除、分类、搜索、常用标记和 `{变量}` 填写
- 可选的目标、背景、输出格式与限制条件，生成可编辑提问草稿
- 选中 GPT 回复后引用追问，内置解释、举例、翻译、检查依据和自定义动作
- 模板与追问追加到已有输入末尾，支持撤销；保留中文输入法组合输入，不自动发送
- 正文宽度、字号、行距和专注模式；折叠长消息与代码块，导出保留完整内容
- 单条消息收藏、备注、搜索、来源定位、复制、Markdown 导出与取消收藏撤销
- 独立本地资料管理页、手动资料空间、JSON 备份恢复、清除当前空间资料
- 收藏保存内容快照，原消息变化或无法定位时仍可查看快照
- 可选开启文字草稿恢复：按会话、标签页和资料空间保存，刷新后可手动恢复，支持过期与立即清除

### 对话导出

- 导出当前 ChatGPT 对话为 `.md` 或独立 `.html`
- 按消息序号范围导出，例如仅导出第 5～12 条
- 在 ChatGPT 页面逐条勾选不连续消息，例如仅导出第 1、3、8 条
- 助手面板顶部提供“导出”入口；浏览器工具栏仍可直接打开导出弹窗
- 按角色筛选：用户消息、ChatGPT 回复
- 可选角色标题、导出元信息、来源链接和消息分隔线
- HTML 支持跟随系统、浅色和深色主题，并带打印样式
- 保留常见富文本：标题、列表、链接、图片、引用、代码块和表格
- 从 KaTeX、MathJax、MathML 及常见公式属性恢复 LaTeX，避免上下标、求和符号和分段公式错乱
- 导出前预览、复制到剪贴板、自定义安全文件名
- 右键菜单快速导出 Markdown / HTML
- 快捷键 `Alt + Shift + M` 快速导出 Markdown
- 扩展设置与主动收藏的内容保存在浏览器本地；扩展自身不上传对话正文

> 当前版本聚焦“当前已打开的单个对话”。批量历史会话导出、附件下载等规划见 [TODO.md](./TODO.md)。

## 安装

### Chrome

1. 打开 `chrome://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录：`/Users/qsx/code/export_chat_gpt`。
5. 打开或刷新 `https://chatgpt.com/`。

### Edge

1. 打开 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本项目目录并刷新 ChatGPT 页面。

## 使用方法

### 日常使用

1. 在 ChatGPT 网页点击右侧“✦ 使用助手”，或点击扩展弹窗中的“打开增强面板”。空白新对话也可使用模板和设置。
2. 在“目录”和“搜索”中定位消息；在消息旁点击“☆ 收藏”，长消息和代码块还会显示折叠按钮。
3. 在“模板”中选择模板并填写变量，预览会自动更新，可直接插入输入框。插入只追加文本，由你检查后发送；输入框不可用时可复制草稿。
4. 在 GPT 回复中选中一段文字，点击“引用追问”，选择动作并编辑草稿。
5. 在“阅读”中调整排版；在“设置”中关闭不需要的模块、编辑自定义追问、备份或恢复资料。
6. 切换 ChatGPT 账号时，手动选择对应资料空间。空间选择仅作用于当前标签页，扩展不自动识别账号。

浏览器弹窗可直接进入“提示词模板”“搜索对话”“我的收藏”；“模板与收藏管理”打开独立设置页，无需先打开一个有消息的会话。

切换助手标签或收起面板会保留当前填写内容和滚动位置；这些临时草稿在刷新页面后清除。模板预览经手动修改后不会再被变量输入覆盖，需要重新生成时点击“更新预览”。重复点击插入不会追加同一份未改动的草稿。窄窗口定位消息或插入草稿后，面板自动收起。

### 草稿恢复

1. 在助手“设置”中勾选“草稿”（默认关闭），可选择保留 1、7 或 30 天。
2. 此后编辑 ChatGPT 输入框时，文字会自动保存到本机。刷新后点击助手顶部“恢复草稿”，预览或修改内容，再点击“恢复到输入框”。已有输入会保留，不会自动发送。
3. 同一会话的不同标签页各存一份，列表标注当前或其他标签页；独立管理页的“草稿”可查看当前空间所有会话的已存内容。
4. 发送后，确认页面出现对应用户消息和助手回复文字才清理；无法确认成功时保留草稿，也可手动删除。
5. 在设置中可立即清除当前空间草稿。关闭草稿功能也会清除当前空间的草稿；其他空间不受影响。

草稿只保存文字，不包含附件，也不纳入模板和收藏备份。恢复备份后需重新开启此功能。到期内容不可恢复，并在下次访问或启用页面的定期检查时清理。模板面板中的临时表单仍只保留在当前页面内存中。

### 导出

1. 在 ChatGPT 打开希望导出的具体对话。
2. 等待对话内容加载完毕，然后点击助手面板顶部的“导出”按钮；也可以点击浏览器工具栏中的扩展图标。
3. 选择 Markdown 或 HTML 与消息范围。需要调整角色标题、导出信息、主题或文件名时，展开“排版与文件名”。
4. 如需导出不连续消息，点击“在页面逐条选择”，在 ChatGPT 页面勾选消息后点击“完成选择”，会自动打开导出设置。如果浏览器未能打开弹窗，可点击“继续导出”重试或点击扩展图标，选择结果会保留。
5. 可先展开“内容预览”，再点击“导出文件”或“复制”。

逐条选择模式支持全选、反选和清空，也可以按 `Esc` 取消。勾选结果只在当前页面与本次弹窗中临时保留；导出设置弹窗关闭后会自动清理，不会写入 ChatGPT 页面数据或浏览器持久存储。

也可以在 ChatGPT 页面点击右键直接快速导出，或使用 `Alt + Shift + M`。

## 导出格式说明

### Markdown

输出包含可选 YAML Front Matter、会话标题和按角色划分的消息。适合 Obsidian、Notion、GitHub、静态站点或版本管理。

公式会优先读取页面保存的 LaTeX 源码，并统一输出为 `$...$` 或 `$$...$$`。例如 `dp_i`、`S[j]-S[i-1]`、`\cdots` 等不会再退化为重复或错位的可视文本。

### HTML

输出是单一 HTML 文件，样式已经内嵌，不需要扩展即可打开和打印。文本内容可离线阅读；远程图片仍依赖原图片 URL 是否有效。

## 隐私与权限

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 读取用户主动打开并点击扩展的 ChatGPT 标签页 |
| `clipboardWrite` | 在用户点击“复制”时写入导出内容 |
| `scripting` | 扩展刚安装而页面尚未刷新时注入读取脚本 |
| `storage` | 在浏览器本地保存导出选项、增强设置、模板、主动收藏的内容快照和备注，以及明确开启后的文字草稿 |
| `contextMenus` | 提供右键快捷导出 |
| ChatGPT 站点访问 | 仅在 `chatgpt.com` / `chat.openai.com` 提取当前页面已显示的消息 |

扩展没有后端、埋点或远程脚本，不调用模型 API，不需要 API Key。搜索和阅读索引仅在当前页面内存中维护；模板、设置及主动收藏的正文持久保存在浏览器本地；明确开启草稿功能后，输入框的文字草稿也会保存在本机。点击“设置”可以备份、恢复或清理当前资料空间，原有导出设置与其他空间不受影响。

提示词和追问只在你主动发送后交由 ChatGPT 处理。JSON 备份包含收藏正文和备注。普通资料空间用于手动区分不同用途或账号，不与 ChatGPT 官方 Project 同步。

```bash

```

## 已知限制

- ChatGPT 页面 DOM 和输入编辑器会变化；若站点改版，选择器或安全插入能力可能需要维护。插入失败时可以使用复制草稿。
- 插入后的草稿已被手动修改时，扩展不会用旧草稿覆盖新内容；可使用输入框自己的撤销功能。
- 来源会话没有打开、原消息已变化或没有稳定消息标识时，收藏可能无法精确定位，仍可查看本地快照。
- 浏览器本地存储有容量限制，保存失败会明确提示；请定期导出备份。草稿不在备份中，重要草稿可单独复制。
- 草稿保存有 350ms 防抖；离开页面时尽力提交已捕获文字，浏览器崩溃或扩展失效前尚未写入的内容无法保证恢复。
- 只能导出当前页面中已经加载的内容；尚未滚动加载的分支或历史内容不会被自动请求。
- HTML 中的远程图片不会自动内嵌，原链接失效后图片可能无法显示。
- Canvas、交互式图表、语音、视频和部分自定义 GPT 小组件目前只能保留可读取的文本。
- 公式以可恢复的 LaTeX 源码保存；若页面只提供 MathML 图形且没有 TeX 注释或替代文本，仍可能只能保留可读文本。独立 HTML 当前不内置 MathJax/KaTeX 渲染器。
